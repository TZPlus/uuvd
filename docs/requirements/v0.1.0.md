# 需求：uuvd v0.1.0 — 最小虚拟屏工具

- 状态：开发中
- 日期：2026-11-15
- 关联分支：feature/骨架（新建仓库，首个分支）
- 关联 worktree：无

## 背景
UU远程 的 Mac 被控端没有「超级屏」功能，iPad 远程时黑边+字小。UUyc-companion 解决了但已停更且功能臃肿；Snug 转向手机竖屏场景。需要一个自己的、功能最小、可维护的版本。

## 验收标准
- [ ] UU远程 连入时，从窗口文字识别控制端设备名，按 config.json 里登记的分辨率建 HiDPI 虚拟屏并设为主屏
- [ ] 断开 15 秒重连窗口后才撤屏；窗口期重连保留虚拟屏
- [ ] 撤屏后还原物理屏分辨率与显示器布局（含异常退出残留恢复）
- [ ] 连接判定三路信号（覆盖窗口 / 控制端表格 / 推流日志），只认正面证据、断开需全部缺席
- [ ] 稳定序列号建屏（防 ColorSync ICC 膨胀），建屏冷却 8 秒防自激振荡
- [ ] 物理屏批量恢复失败时逐个恢复并清理失效 ID
- [ ] 菜单栏最小 UI：状态 / 立即恢复（⌃⌥⌓9）/ 暂停 / 打开配置目录 / 退出
- [ ] swift build + swift test 全绿
- [ ] --simulate 本地自测建屏/还原链路通过
- [ ] 物理屏关闭功能默认关，README 写明风险

## 非目标（v0.1 明确不做）
看门狗 LaunchAgent、设置窗口 UI、手机竖屏/窗口管理/手势、自动更新、推 UU远程 官方接口
